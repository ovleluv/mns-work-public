# 지형 이동 테스트

지형별 테스트 코드와 실제 실행 결과를 함께 보관합니다. 전체 24종에 경로·규칙 검사를 확장하여 1,272건(유닛별 53건)이 모두 통과했습니다. 기존 7종 대비 추가된 17종의 901건도 모두 통과했습니다. 수정 전 12건 실패 결과는 results/before_forest_road_fix에 보존했습니다. 먼저 [종합 결과](summary.md)와 [결함 분석](findings.md)을 확인하세요.

## 실행

프로젝트 루트(mns_v49_7_work)에서:

~~~powershell
python tests/terrain/run_suite.py
python tests/terrain/build_unit_report.py
~~~

평지 → 강 → 도하 → 다리 → 도로 → 숲 → 호수 → 건물 → 고도·경사 → 성긴 숲 순서로 하나씩 실행합니다. 앞 지형이 실패해도 나머지를 실행하고, 전체 종료 코드는 실패가 하나라도 있으면 1입니다. 실행마다 지형별 *_results.md, results/*.log, results/*.xml, results/results.json 및 summary.md를 갱신합니다. findings.md는 해당 실행에 대한 수동 분석 기록입니다. 초기에 보존한 initial_pytest.xml은 최종 결과와 별개입니다.

특정 지형만 검사하려면:

~~~powershell
python -m pytest -q tests/terrain/test_river.py
~~~

위 직접 pytest 명령은 보고서를 재생성하지 않습니다. 보고서 갱신은 run_suite.py를 사용하세요.

## 유닛과 판정 기준

config/toe_templates.json에 등록된 24종 전체를 검사합니다. 대상 목록은 support.py의 UNITS에 있으며 보병·기관총·전차·견인포·기계화보병·차량화보병 및 단일 차량을 포함합니다. 실제 TO&E를 로드하고 각 유형의 IND/SQD/PLT/COY/BN 편제를 명시합니다. 로더가 유닛 유형을 바꾸면 즉시 실패합니다.

시드 7, dt=0.25/1/20초. 작은 합성 지도에서 적·교전 없이 계획 경로 및 _move_toward()의 매 이동 선분을 검사합니다. 도착은 엔진 기준인 목적지 반경 3m 이내입니다. 최대 관찰 시간은 일반 편제 1200초, 편제 감속 대상인 중대·대대 12000초입니다. 저속 하한이 기존 속도의 10%이므로 중대·대대의 관찰 시간을 확장했으며, 도착 가능한 경로에서 연속 12틱 정지하면 시간 여유와 무관하게 실패합니다. 통행 불가 대조군은 최소 40초와 13틱 이상 관찰하여 잘못된 도착이나 위치 변경을 검출합니다.

엔진 통행 함수와 별도로 강 양안 좌표, 교량 통과 구간의 폭, 건물·숲·호수 직사각형과 선분 교차를 검사합니다. 평지 대비 이동 시간 비교도 사용합니다. 경로 계획과 실제 이동의 동일 함수 호출만으로 정확성을 판단하지 않습니다.

급경사는 국소 선분의 계획 차단만 확인합니다. 나머지 이동 검사도 전술 명령 처리나 다수 유닛 통합 실험을 대신하지 않습니다. 상세 한계는 findings.md에 기록했습니다.

## 편제별 최종 속도 감속

`mnsim/mobility.py`가 실제 이동·경로 비용·상세 보고서의 속도 계산을 공유합니다. 상태·지형·장비 가동률·경사 배율을 모두 적용한 속도를 V라 하면 최종 속도는 `max(V × 0.10, V − 감속량)`입니다. 감속량은 소대 0, 중대 0.5km/h, 대대 1.0km/h이며 `unit.echelon`을 사용합니다. 개별·분대 및 나머지 편제에는 차감하지 않습니다. 기존 기준 속도는 바꾸지 않습니다.

저속 하한에서는 중대·대대 속도가 같아질 수 있습니다. V=0인 정지·기동 불능 상태는 그대로 0이고 통행 제한도 유지됩니다. 경로 계획은 대기 중 이동 명령도 계획할 수 있도록 MOVING 기준을 사용하며, 실제 이동은 현재 상태를 사용합니다. 경로 비용이 0 속도 구간에 가상의 최소 속도를 부여하지 않도록 했습니다.

`python -m pytest -q tests/test_echelon_mobility.py`로 편제 간 차이, 실제 이동, 저속 하한, 정지·통행 불가, 손상·경사 적용 순서, 통합·분리 후 편제 감속을 확인합니다.
