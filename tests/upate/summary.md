# 최신 엔진 교전 재실험 완료

현재 Unit.firepower() 기반 엔진으로 모든 실행을 새로 수행했다. 이전 실험 결과를 복사해 집계하지 않았다.

| 구분 | 배치 조합 | 시뮬레이션 | pytest | 사격 미발생 | 상태 위반 |
|---|---:|---:|---:|---:|---:|
| 1대1 | 44 | 132 | 47 passed | 0 | 0 |
| 다대다 | 276 | 828 | 287 passed | 0 | 0 |

총 320개 배치 조합, 960회 시뮬레이션, 334개 pytest 검사 통과.

각 실험의 시드는 7/19/41이다. 다대다에는 동종 편제의 횡대·종대·엇갈림과 3:3·4:2·2:4 구성을 모두 포함한다.

현재 코드와 기록된 소스 SHA-256 일치를 확인했다. audit.json에는 배치별 입력·출력 파일 해시를 기록했다. 참여량 0명의 직사 이벤트도 0건이다.

- [1대1 상세 요약](one_vs_one/results/summary.md)
- [1대1 BLUE/RED 생존자](one_vs_one/results/survivors.md)
- [다대다 상세 요약](many_vs_many/results/summary.md)
- [다대다 BLUE/RED 생존자](many_vs_many/results/survivors.md)
- [전체 파일 검증 집계](verification.json)

주의: 1대1은 편제 하나씩을 뜻한다. TIME_LIMIT는 시간 종료이며 승패·무승부를 뜻하지 않는다. 사격 발생 검사는 양측 중 적어도 한쪽의 사격을 확인한다. native 교전 검사 통과가 순수 란체스터 법칙 일치 또는 실제 전투 예측 정확도를 보장하지 않는다.

초기 병렬 테스트 수신부 오류를 수정한 뒤 전체 실험을 재실행했다. 여기의 pytest 결과와 집계는 수정 후 최종 실행이며, 엔진 코드는 이번 실험 중 변경하지 않았다.
