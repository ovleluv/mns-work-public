# TDG3 검증 실행

프로젝트 폴더(`editor.py`, `main.py`가 있는 폴더)에서 실행합니다.
테스트 의존성은 다음 명령으로 설치할 수 있습니다.

```powershell
python -m pip install -r requirements-dev.txt
```

## 빠른 회귀 검사

```powershell
python -m pytest -q tests/test_tdg3_scenario.py tests/test_tdg3_execution.py tests/test_tdg3_replay.py tests/test_tdg3_navigation_limits.py tests/test_continuous_terrain_movement.py tests/test_external_bml_missions.py
```

- 실제 `tdg3.json`과 양측 BML을 읽습니다.
- 편제 중복, 대전차 발사기/탄약 수량, 객체 사이의 탄약 공유 오류를 검사합니다.
- BML 대체/추가와 지정되지 않은 부대의 기존 명령 유지를 검사합니다.
- B Security의 송수신 차단과 180초 후 사전 복귀 명령 시작을 검사합니다.
- 보병 도하, 차량의 교량 의존성, 교량 파괴 시 차량 통행 차단을 검사합니다.
- 무장팀에서 한 명만 생존했을 때 집결지 복귀와 이후 대기를 검사합니다.
- 전차 출발 시간 제한, navigation team의 시간 초과 분기, 전사 부대의 이동 중지를 검사합니다.
- 같은 프로세스에서 동일 시드로 실행한 일부 부대의 관측·사격 재현성, 상대 팀 명령 거부, 부대별 phase 진행을 검사합니다.
- 저장 로그 감사기가 무전·탄약·시간·명령 오류를 실제로 탐지하는지도 검사합니다.

## 저장한 실험 로그 검사

```powershell
python -m pytest -q -s tests/test_tdg3_replay.py --tdg3-replay logs/replay.jsonl
```

원본 로그는 변경하지 않습니다. 검사 결과와 `tdg3_replay_audit.json`의 임시 저장 경로를 출력합니다.
검사 대상은 현재 TDG3 편제와 두 BML을 사용한 로그입니다. 로그에 설정 해시가 없으므로 과거의 다른 설정과 완전히 같은 실험인지는 증명하지 못합니다.
짧은 로그도 검사할 수 있으며, 발생하지 않은 도달 이벤트는 미완료로 표시합니다.
`last_event_time_s`는 마지막 사건 시각입니다. 이후 사건 없이 실행이 계속될 수 있으므로 저장 로그만으로 전체 실행 시간을 추정하지 않습니다.

## 1시간 통합 실험

```powershell
python -m pytest -q -s tests/test_tdg3_execution.py --run-tdg3-integration
```

기본 시드 7, 시뮬레이션 시간 3600초, 0.25초 간격으로 실행하므로 수 분 이상 걸릴 수 있습니다.
기본 pytest 실행에서는 이 검사와 파일을 지정하지 않은 저장 로그 검사를 건너뜁니다.
병력이 이유 없이 늘어나거나 음수가 되지 않는지, 전사한 객체가 움직이지 않는지, 차량이 다리 밖으로 도하하지 않는지, 탄약이 증가하거나 음수가 되지 않는지 등을 실행 중 검사합니다.
`tdg3_outcome.json`에 교량 진입, 남쪽 출구 60m 이내 도달, 손실, 입력 파일 해시를 기록합니다.
통합 보고서의 `duration_s`는 실제 진행한 시뮬레이션 시간이며, `last_event_time_s`와 별도로 기록합니다.
실행 간 비교를 위해 시나리오 시드, 시간 간격, Python 버전, 운영체제, `PYTHONHASHSEED` 환경 변수도 기록합니다.

## 결과 해석

**테스트 통과는 BLUE 승리나 최적 전술을 뜻하지 않습니다.**

원문에서 확정된 사항(전차 4대, 트럭 2대, 대전차 무기 2기)과 현재 모델의 가정(BLUE 35명, RED 보병 27명, B Security 생존·자력 복귀, 확대한 지형)을 구분합니다.
가정을 바꾸는 실험은 관련 기준 테스트도 함께 검토해야 합니다. B Security 자동 복귀 검사는 PDF의 필수 행동을 주장하지 않고, 현재 채택한 가정의 실행을 확인합니다.

해설의 목적은 M Company의 방어 준비에 필요한 시간을 확보하는 것입니다. 현재 지도에서 남쪽 출구는 그 목적을 평가하는 대리 지표입니다.
따라서 **출구 도달 시간, 손실, 전개에 걸린 시간**을 함께 검토해야 합니다. 특정 시각의 승패나 전차 4대 격파를 정답으로 고정하지 않습니다.

저장된 JSONL은 사건 로그이며 연속 위치 기록이 아닙니다. `CROSS-BRIDGE` / `SOUTH-ROAD` 명령 완료 시각은 정확한 강 진입·출구 경계 통과 시각과 다릅니다.
저장 로그만으로 지형 통행과 순간 이동을 증명할 수 없으므로, 이 항목은 위치를 직접 관찰하는 통합 실험에서 검사합니다.
통합 실험은 각 틱의 시작점·중간점·끝점 표본 검사에 공통 선분 통행 검사도 함께 사용합니다. 차량 폭과 대형의 물리적 통과를 증명하는 검사는 아닙니다.
재현성 단위 검사는 제한된 부대 구성과 같은 프로세스만 대상으로 하며, 별도 프로세스나 Python 버전 사이에서 전체 전투 결과가 일치함을 보장하지 않습니다.

## 발견한 지형 통행 문제와 수정

기존 경로 검사의 간격 샘플링과 이동의 도착점 검사만으로는 두 통행 가능 지점 사이의 짧은 숲 구간을 놓칠 수 있었습니다.
실제 시드 7 실험의 896초 시점에는 R-T55-3의 이동 중간점이 F3 경계 안쪽 약 3.3mm에 놓였습니다.

공통 선분 통행 검사와 우회 처리를 엔진에 적용했습니다. `test_tdg3_navigation_limits.py`의 두 검사는 이제 `xfail` 없이 통과해야 하는 정상 회귀 검사입니다.
구현 범위와 여섯 가지 성공 기준의 검사 방법은 아래 [연속 지형 통행 검사](#연속-지형-통행-검사) 절에 정리했습니다.

수정 전 사용자가 제공한 통합 실행 결과는 **13 passed, 1 failed (332.77초)**였습니다.
3600초 실행을 완료한 뒤 `R-T55-3`, 시뮬레이션 896초의 통행 불가 표본 1건 때문에 실패했습니다.
새 실행은 결과 보고서의 `geometry_violation_count`와 `wall_time_s`로 통행 위반과 성능을 함께 확인합니다.

## 연속 지형 통행 검사

TDG3의 R-T55-3는 896초에 양 끝점이 통행 가능한 이동 선분으로 숲 모서리를 잘랐습니다.
경계 안쪽 깊이는 약 3.34mm, 숲 내부 이동 길이는 약 23.4cm였습니다.
`TerrainModel.segment_passable()`을 경로 탐색과 실제 이동에서 함께 사용하도록 수정했습니다.
시나리오·지형·BML 입력 파일은 변경하지 않았습니다.

### 처리 방식

- 숲 등 다각형 경계와의 교차 지점으로 이동 선분을 나눕니다.
- 도로·강·교량은 기존 점 판정과 동일하게 폭이 있는 선분과 둥근 끝부분으로 취급합니다.
- 각 경계와 경계 사이 구간에서 기존 부대별 통행 규칙을 적용합니다. 숲 내부의 도로 통행, 정상 교량, 보병 도하와 수륙양용 능력을 유지합니다.
- 부대에게 제한을 주지 않는 일반 지형은 경계 계산에서 제외합니다. 경사와 이동 시간 비용의 기존 샘플링은 유지합니다.
- 이동 직전에 실제 한 틱의 선분도 검사합니다. 차단되면 이동하지 않고 경로 캐시를 버립니다.
- 현재 위치에서 캐시된 경유점으로 가는 길이 막혀도 재탐색합니다. 교량 상태뿐 아니라 새로 추가된 장애물도 반영합니다.
- 기본 도로·교량·건물 경로로 목적지에 도달하지 못하면 통행 불가 영역의 모서리 주변에 경유점을 추가해 재탐색합니다. 후보는 점 통행 검사와 시나리오 지도 범위 검사를 통과해야 합니다.
- A*가 실제로 방문하는 지점의 연결만 검사합니다. 숲 우회 경유점이 늘어도 모든 지점 쌍을 미리 계산하지 않습니다. 가까운 목적지를 찾을 때 불필요한 먼 경유점 쌍까지 검사하지 않는지도 작업량 상한 테스트로 확인합니다.
- 경유점 3m 전에 멈추어 우회를 끝내지 못하던 처리를 없앴습니다. 최종 목적지의 기존 도착 판정 반경은 유지합니다.
- 1m 미만의 경로도 검사를 생략하지 않습니다. 시작·목적지 노드는 1mm 좌표 중복 제거 대상에서 제외합니다.

### 경계 정책과 범위

이동에서는 다각형 경계를 닫힌 영역으로 취급하므로 금지 영역에 접하거나 경계를 따라가는 경로도 차단합니다.
도로·교량 경계는 통행 영역에 포함됩니다. 수치 비교 기준은 `1e-8 m`이며, 숲을 수 mm 축소해 실패를 숨기는 처리는 없습니다.
일반 LOS 다각형 조회는 기존 규칙을 유지합니다.

이 변경은 부대 중심점의 통행 검사입니다. 차량 폭·회전 반경·부대 대형은 추가하지 않습니다.
매우 좁은 통로나 복잡한 다각형에서 희소 경유점만으로 모든 존재 가능한 경로를 찾는다고 보장하지 않습니다.
고도 경사 판정과 수영에 따른 무기 유기 같은 지형 진입 효과는 별도 기존 처리입니다.

해당 테스트 안에서만 보병 도하를 금지해 교량 의존 조건을 명시했습니다. TDG1 입력 파일을 변경한 것은 아닙니다.

성능 수치는 운영체제 부하에 영향을 받으므로 일반 회귀 테스트에서 절대 실행 시간을 합격 기준으로 고정하지 않습니다.
